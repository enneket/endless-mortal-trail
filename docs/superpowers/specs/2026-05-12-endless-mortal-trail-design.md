# 《人间无尽途》游戏设计文档

> 日期：2026-05-12
> 状态：设计完成，待实现

## 一、项目概述

**人间无尽途**是一款基于 Web 的国风文字冒险游戏。玩家扮演"渡途人"，穿行于无穷无尽的"衍世人间"，体验人间百态。游戏无固定终点，旅途永无止境。

### 核心特点
- 无限随机关卡，永远不重样
- 开放场景，纯文字叙事
- 清冷漂泊感，国风氛围
- 分支选择型交互
- 打字机效果逐字呈现

### 技术栈
- 前端：HTML / CSS / JavaScript（无框架）
- 存储：localStorage
- 部署：纯静态文件，可直接打开或部署到任意静态托管

│   └── app.js                 # 主入口，初始化引擎

### 核心流程

1. `app.js` 初始化引擎，加载存档（如有）
2. `story-engine.js` 读取当前场景 JSON
3. `renderer.js` 用打字机效果逐字显示文本
4. 玩家选择选项 → `story-engine.js` 处理跳转 / 状态变更
5. 循环直到玩家主动退出或触发特殊节点

## 三、场景数据格式

每个场景是一个独立的 JSON 文件。

### JSON Schema

```json
{
  "id": "string",              // 场景唯一 ID
  "title": "string",           // 场景标题
  "atmosphere": {
    "time": "string",          // 时间：黎明 / 白昼 / 黄昏 / 深夜
    "weather": "string",       // 天气：晴 / 阴 / 雨 / 雪 / 雾
    "mood": "string"           // 氛围：迷茫 / 宁静 / 紧张 / 诡异
  },
  "texts": [                   // 文本段落数组
    {
      "content": "string",     // 文本内容
      "delay": "number"        // 段落前停顿（毫秒）
    }
  ],
  "choices": [                 // 选项数组
    {
      "text": "string",        // 选项文本
      "target": "string",      // 目标场景 ID
      "effects": {             // 状态变更
        "karma": "number",
        "wisdom": "number",
        "courage": "number",
        "mood": "string",
        "addItem": "string",
        "removeItem": "string",
        "setFlag": "string"
      },
      "condition": {           // 显示条件（可选）
        "hasItem": "string",
        "hasFlag": "string",
        "minKarma": "number",
        "mood": "string"
      }
    }
  ],
  "onEnter": [],               // 进入场景时触发的事件
  "onExit": []                 // 离开场景时触发的事件
}
```

```

│                                     │

│                                     │
│                                     │
│   ┌─────────────────────────────┐   │
│   │  向微光走去                 │   │  ← 选项按钮，边框无底色
│   └─────────────────────────────┘   │

```

### 视觉规范

| 元素 | 属性 | 值 |
|------|------|-----|
| 背景色 | background | `#0a0a0a` |
| 正文文字 | color | `#e0e0e0` |
| 正文字号 | font-size | `18px`（移动端 `16px`）|
| 正文行高 | line-height | `1.8` |
| 标题颜色 | color | `#666666` |
| 标题字号 | font-size | `14px` |
| 选项边框 | border | `1px solid #333333` |
| 选项悬停 | border | `1px solid #666666` |
| 状态栏颜色 | color | `#444444` |
| 状态栏字号 | font-size | `12px` |

### 字体

```css
font-family: -apple-system, "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
```

### 打字机效果

- 速度：每字 50-80ms
- 段落间停顿：由场景 JSON 的 `delay` 字段控制
- 可点击跳过：点击任意位置立即显示全部文字

### 场景切换

- 旧文字淡出：300ms opacity 0→1
- 停顿：200ms
- 新文字开始打字

### 响应式

- 移动端（<768px）：文字 16px，选项全宽，上下边距减小
- 桌面端：内容区域最大宽度 680px，居中显示

## 五、状态与存档系统

### 玩家状态结构

```json
{
  "player": {
    "name": "渡途人",
    "title": "无名行者"
  },
  "stats": {
    "experience": 0,
    "wisdom": 0,
    "courage": 0,
    "karma": 0,
    "mood": "迷茫"
  },
  "inventory": [],
  "history": [],
  "currentScene": "01_awakening",
  "currentChapter": "chapter1",
  "flags": {},
  "playTime": 0,
  "createdAt": null,
  "savedAt": null
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `experience` | number | 阅历值，游历人间、做出选择时增长 |
| `wisdom` | number | 智慧，观察、思考类选择增长 |
| `courage` | number | 勇气，果断、冒险类选择增长 |
| `karma` | number | 因果值，善恶倾向（正=善，负=恶）|
| `mood` | string | 当前心境：迷茫 / 好奇 / 谨慎 / 淡然 / 桀骜 |
| `inventory` | array | 行囊物品列表 |
| `history` | array | 已经历的场景 ID |
| `flags` | object | 标记位，记录关键选择 |
| `playTime` | number | 游玩时长（秒）|

### 存档机制

- **自动存档**：每次做出选择后自动保存到 localStorage
- **存档槽位**：3 个槽位
- **存档键名**：`emt_save_1` / `emt_save_2` / `emt_save_3`
- **存档显示**：场景名 + 心境 + 游玩时长 + 时间戳
- **无云端存档**，纯本地

### 因果联动规则

1. `karma` 值影响后续场景中 NPC 态度和选项可用性
2. `flags` 记录关键选择（如 `saved_old_man`、`took_jade_pendant`），后续章节可引用
3. `mood` 影响文字描述的细微变化（同一场景，不同心境下文字略有不同）

**场景数量**：12 个

### 各场景概要

| 场景 | 标题 | 核心内容 |
|------|------|----------|
| 01 | 裂隙初醒 | 渡途人在虚空中醒来，失去记忆，看见远处微光 |
| 02 | 向光而行 | 向微光走去，遇到无名老者，首次对话 |
| 03 | 观察虚空 | 留在原地观察，发现漂浮的碎片，获得无名玉佩 |
| 04 | 呼喊试探 | 大声呼喊，虚空震动，感知到"衍世"的存在 |
| 05 | 裂隙之门 | 三条路径汇合点，老者揭示"衍世人间"设定，选择方向 |
| 06 | 雾中古村 | 进入第一个人间——雾中古村，感受烟火气息 |
| 07 | 山间古道 | 进入山野人间，清冷孤寂的氛围 |
| 08 | 酒肆夜话 | 在村中酒肆遇到落魄书生，听他讲述人间故事 |
| 09 | 村中秘事 | 发现古村隐藏的秘密，做出选择 |
| 10 | 山中隐者 | 遇到隐世老者，经历心境试炼 |
| 11 | 孤峰远眺 | 登上山巅，看见万千人间的幻象 |
| 12 | 踏上下一程 | 离开第一章，根据此前选择进入不同的人间 |

### NPC 设计

**无名老者**（场景 02、05）
- 身份：裂隙中的引路人，似曾相识又完全陌生
- 性格：淡然、温和、话语不多但字字珠玑
- 作用：揭示世界观，引导玩家理解"渡途人"身份
- 台词风格：古风简练，留白多

**落魄书生**（场景 08）
- 身份：困在雾中古村的旅人，满腹经纶却无处施展
- 性格：忧郁、善谈、有些自嘲
- 作用：展示 NPC 有独立人格和执念
- 台词风格：文雅但带几分苦涩

**隐世老者**（场景 10）
- 身份：山中修行多年的隐者
- 性格：沉默寡言，偶尔发问直击内心
- 作用：心境试炼，影响玩家的命格倾向
- 台词风格：极简，以问代答

### 物品设计

**无名玉佩**（场景 03 获得）
- 描述：一块温润的古玉，上面刻着看不清的纹路。握在手中，有种奇异的安心感。
- 作用：后续章节可触发隐藏剧情

**残破古籍**（场景 08 获得）
- 描述：一卷残破的书册，字迹模糊，依稀可辨是某个朝代的野史。
- 作用：可在后续人间中交换信息或触发知识类选项

## 七、随机生成系统（预留）

第一章为手工编写，但架构预留了随机生成接口：

### 生成模板

```json
{
  "templates": {
    "market": {
      "nouns": ["老街", "古镇", "市集", "巷弄"],
      "atmospheres": ["热闹", "冷清", "黄昏", "清晨"],
      "npcs": ["卖花老妪", "算命先生", "酒馆掌柜"],
      "events": ["有人争吵", "孩子在追逐", "远处传来琴声"]
    }
  }
}
```

### 生成规则

1. 从模板中随机组合场景元素
2. 根据玩家当前 `mood` 和 `karma` 调整氛围
3. NPC 从数据库中随机抽取，赋予当前场景相关对话
4. 保证同一模板不连续出现
